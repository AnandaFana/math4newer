# 统计学习路线图

## 已完成
- 第 01 课：平均数——用“公平分配”理解总量 ÷ 个数。
- 第 02 课：中位数——排序后观察中间位置。
- 第 03 课：众数——识别最常见的选择。
- 第 04 课：波动——比较范围和标准差。
- 第 05 课：概率——用比例描述可能性。
- 统一课程模板：独立 HTML、离线脚本、拖动实验、恢复默认、深色阅读模式。

## 后续模块
1. 中位数：排序后站在队伍中间，理解为什么它更抗极端值。
2. 众数：最常见的选择，区分“流行”与“平均”。
3. 波动：同样平均数，为什么体验可能完全不同？
4. 概率：把“可能发生”变成可比较的比例。
5. 抽样与偏差：为什么问错人会得到错答案？
6. 相关与因果：一起变化不等于互相造成。

## 家庭讲解建议
先让听众猜答案，再拖动数据；用“公平分一分”替代一开始讲符号。每节只引入一个新词，并保留一个能带回日常的提问。
