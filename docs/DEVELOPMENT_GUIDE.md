# 小小统计学：开发与内容协议

## 产品目标
面向没有统计学背景的家庭学习者，用“生活问题 → 可视化解释 → 小实验 → 带回家的问题”降低概念门槛。第一版为纯静态、离线可用页面，不依赖框架或网络服务。

## UI 约定（复用优先）
- **页面骨架**：左侧课程导航、顶部面包屑、主内容卡片、右侧路线卡；窄屏隐藏侧栏并保留顶部导航。
- **教学节奏**：每个模块保持 4 段：故事 / 概念 / 实验 / 一句话带走。
- **视觉语言**：暖白纸张背景、墨绿色强调、黄色提示、珊瑚/蓝色数据系列；避免大面积渐变和装饰性动效。
- **可访问性**：所有控件有可见焦点态和中文 aria-label；颜色不能成为唯一信息；图表应配文字读数。
- **离线打开约定**：入口页使用普通脚本按 `lessons.js` → `app.js` 顺序加载，兼容用户直接双击 `index.html`；不要改回 ES module，除非同时提供本地服务器启动方式。

## 插件化内容协议
后续课程可在 `content/` 放置 JSON，推荐字段：
```json
{
  "id": "median",
  "title": "中位数：站在队伍正中间",
  "audience": "family",
  "sections": [{"type":"story","title":"...","body":"..."}],
  "experiment": {"kind":"distribution","defaults":{}}
}
```
`src/lessons.js` 是轻量课程注册表：每个课程声明 `id`、短标题、完整标题、状态和锚点；新增课程先登记为 `planned`，内容完成后改为 `available`。`src/app.js` 负责当前模块状态和实验；`src/styles.css` 负责共享视觉令牌；内容不应把颜色、间距或 DOM 结构写死在文案里。

## 实验与科学规范
1. 明确数据是否为演示数据，不能把示例结论包装成真实研究结果。
2. 显示公式、输入、输出和可复现的默认值；避免只给漂亮图表。
3. 改变一个变量时说明其他假设；解释平均数受极端值影响等边界。
4. 每个实验需要“恢复默认”能力，随机实验后续应提供种子或记录参数。
5. 新模块必须补充至少一个手机布局检查和一个键盘操作检查。

## 文件管理
- `index.html`：应用壳和可读内容。
- `src/`：可复用的样式令牌与交互逻辑。
- `content/`：未来课程数据，不放构建产物。
- `docs/`：维护协议、研究笔记、版本变更。
- `.acl-recovery/`：工作区权限修复的恢复记录，不属于产品发布内容。

## 迭代协议
新增知识模块时：先写内容大纲和数据假设，再复用卡片/实验组件；若必须改变骨架，先更新本文件并在 `CHANGELOG.md` 记录原因。完成后检查离线打开、窄屏、打印、键盘焦点和数学表述。
